# Resulting dataset README

This dataset deposited at https://doi.org/10.4121/10.4121/06415947-2b9b-4435-833e-e513ae71a6ed contains all files generated by the data processing and subsequent analysis scripts, except for the raw data and initially processed data in the folders `./Data/RawData/` and `./Data/ProcessedData/`. These data can support for repeating the experiments of the unified traffic conflict detection study.

## Data Organisation
- `./Data/DynamicFigures/` contains dynamic visualisations (e.g., animated GIFs and videos) of traffic conflict examples.
- `./Data/InputData/100Car/` includes processed crash and near-crash events in HDF5 and CSV formats. Files here are used as input for conflict analysis and model evaluations.
- `./Data/InputData/highD_LC/` holds processed train, val, and test sets of input features derived from the lane-changing interactions in the highD dataset.
- `./Data/OutputData/` stores results from warning analyses and intensity evaluations. 

## Data Variables and Column Headings
The dataset includes several processed tables with standardised column headings. Example variables include:
- **track_id**: Unique identifier for each vehicle track.
- **frame_id**: The frame or time index for recorded vehicle states.
- **x, y**: Positional coordinates.
- **psi**: Heading angle (in radians) indicating vehicle orientation.
- **speed, vx, vy**: Overall vehicle speed and its components along the x and y axes.
- **ax, ay**: Acceleration components in the horizontal and vertical directions.
- **width, length**: Vehicle dimensions used to distinguish agent types.
- **laneId**: Identifier for the detected lane.
- **n_hat**: Derived variable representing the unified conflict intensity (often computed via a logarithmic transformation of spacing distributions).
- **TTC, DRAC, PSD, Unified**: Metrics for conflict evaluation where TTC (Time-To-Collision), DRAC (Deceleration Rate to Avoid Collision), and PSD (Proximity-based Surrogate) are compared to the proposed unified metric.
- **avg_intensity, avg_TTC**: Averaged values of computed metrics over the duration of a conflict event.

## Usage Notes
- Data files are stored in standard formats (HDF5 or CSV) and can be loaded using Python packages such as pandas (e.g., `pd.read_hdf` or `pd.read_csv`).
- Pytorch models are saved in PTH format and can be loaded using `torch.load()`.
- The dataset is structured to facilitate easy access to both input features and output results, enabling straightforward analysis and model evaluation.
- For replication details, experiment code is open-sourced at https://github.com/Yiru-Jiao/UnifiedConflictDetection
